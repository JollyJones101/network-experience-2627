# Supporttickets

Een supportticket is een issue waarmee je een probleem opvolgt dat hulp, analyse of externe input vraagt.

## Werkwijze

1. Maak een support-issue aan.
2. Beschrijf context en impact.
3. Noteer wat je al getest hebt.
4. Voeg relevante logs of screenshots toe, zonder secrets.
5. Noteer de oplossing.
6. Valideer de oplossing.
7. Werk documentatie en changelog bij.
8. Sluit het issue pas wanneer het probleem gecontroleerd opgelost is.

## Minimale inhoud

- titel;
- betrokken component;
- verwachte werking;
- actuele werking;
- analyse;
- uitgevoerde stappen;
- validatie;
- documentatie-impact.
