# Configs

Bewaar hier configuratievoorbeelden, exports of snippets die nuttig zijn voor documentatie.

Regels:

- geen wachtwoorden;
- geen tokens;
- geen private keys;
- geen recovery codes;
- geen volledige exports met secrets;
- gebruik placeholders zoals `<SECRET_IN_BITWARDEN>`.

Noteer bij elk voorbeeld de bedoelde service, softwareversie, bronbestand, eigenaar en manier waarop de echte configuratie wordt uitgerold. Een losse snippet zonder context is geen reproduceerbare configuratie.
