# Webshare

Elke groep zet een webgebaseerde filesharing-service op en publiceert die veilig via OPNsense.

## Mogelijke lichte oplossingen

- File Browser;
- SFTPGo;
- eenvoudige WebDAV-service;
- andere lichte oplossing met motivatie.

Nextcloud mag alleen als jullie aantonen dat dit haalbaar is binnen de RAM-limieten.

## Verwachtingen

- bereikbaar vanaf WAN-kant, klaslokaalnetwerk of opleidingsnetwerk volgens afspraken;
- toegang beveiligd met accounts;
- geen anonieme write-access;
- firewall/NAT/reverse proxy gedocumenteerd;
- upload, download en toegangscontrole getest;
- back-up van gedeelde bestanden.
