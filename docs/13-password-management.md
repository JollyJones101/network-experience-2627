# Password management

Elke groep gebruikt Bitwarden of een door de docent goedgekeurd alternatief.

## Regels

- Geen wachtwoorden in GitHub.
- Geen tokens in tickets.
- Geen private keys in screenshots.
- Geen recovery codes in Markdown.
- Gedeelde secrets staan in de password manager.

## Documenteer wel

- categorieen secrets;
- wie toegang heeft;
- hoe nieuwe wachtwoorden worden aangemaakt;
- hoe wachtwoorden gedeeld worden;
- wat gebeurt bij groepswissel;
- recoveryprocedure;
- verschil tussen documentatie en secrets.
