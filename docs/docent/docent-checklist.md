# Docent-checklist

Gebruik deze checklist als snelle controle tijdens voortgangsmomenten of einddemo.

- [ ] Groepsrepo is eigen clone/fork.
- [ ] Geen secrets in repo.
- [ ] OPNsense is verplichte gateway.
- [ ] Geen toegang tot doos-Proxmox voor studenten.
- [ ] Drie Proxmox-nodes vormen een cluster.
- [ ] Proxmox SDN is aanwezig.
- [ ] User management met beperkte account is getest.
- [ ] Password management is afgesproken.
- [ ] Webshare is veilig gepubliceerd.
- [ ] VPN werkt en is beperkt.
- [ ] Proxmox firewall/security groups zijn gebruikt.
- [ ] n8n-workflow werkt.
- [ ] HA-test is uitgevoerd en beperkingen zijn uitgelegd.
- [ ] Backup/restore is getest.
- [ ] Monitoring/logging aanwezig.
- [ ] Incident of change request volledig opgevolgd.
- [ ] Individuele bijdrage is aantoonbaar.
