# Changelog

Dit bestand houdt belangrijke wijzigingen bij aan de groepsomgeving en documentatie.

Entries kunnen automatisch toegevoegd worden wanneer issues gesloten worden. Voeg manueel extra context toe wanneer dat nodig is.

## Formaat

```text
YYYY-MM-DD - [type] Titel
- Issue: #nummer
- Samenvatting: korte beschrijving
- Validatie: hoe is dit getest?
```
